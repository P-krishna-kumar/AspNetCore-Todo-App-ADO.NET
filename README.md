# ASP.NET Core Todo App (ADO.NET)

This is a simple Todo List web application built using ASP.NET Core MVC and ADO.NET with SQL Server.

## Features
- Add tasks
- View tasks
- Mark task as completed
- Delete task

## Technologies
- ASP.NET Core MVC
- ADO.NET
- SQL Server

## Purpose
This project is created for learning CRUD operations using ADO.NET.
